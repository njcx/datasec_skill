# GB/T 41773-2022 信息安全技术 步态识别数据安全要求

## 基本信息

| 项目 | 内容 |
|------|------|
| 标准号 | GB/T 41773-2022 |
| 中文名称 | 信息安全技术 步态识别数据安全要求 |
| 归口单位 | 全国网络安全标准化技术委员会（TC260） |
| 标准类型 | 推荐性国家标准（GB/T） |
| 发布日期 | 2022 年 10 月 12 日 |
| 实施日期 | 2023 年 5 月 1 日 |

## 标准简介

本标准是生物识别数据安全系列标准之一，专门针对步态识别数据的全生命周期安全要求进行规定，是步态识别技术在安防、门禁、智慧城市等场景应用时的合规参考依据。

## 步态识别数据的特殊性

步态识别数据属于**生物识别信息**，具有以下特殊风险：

- **不可更改性**：步态特征一旦泄露无法更改，风险持久
- **远距离采集性**：可在被识别者不知情的情况下远程采集
- **唯一性**：步态特征具有个体唯一性，泄露后可永久追踪个人
- **敏感性**：属于《个人信息保护法》规定的敏感个人信息

## 适用系统类型

- 公共场所步态识别门禁系统
- 安防监控中的步态分析系统
- 智慧楼宇/园区步态身份验证系统
- 步态数据采集设备及平台

## 主要安全要求

### 一、数据采集安全

- 须明确告知采集目的、方式和用途
- 公共场所部署须设置明显告知标识
- 禁止在未授权区域秘密采集步态数据
- 采集范围应与使用目的相匹配，最小化采集

### 二、数据存储安全

| 要求 | 说明 |
|------|------|
| 加密存储 | 步态特征模板须加密存储，算法不低于国家密码局推荐强度 |
| 访问控制 | 严格限制可访问步态数据的人员权限 |
| 存储期限 | 明确数据保留期限，超期须安全删除 |
| 物理安全 | 存储步态数据的服务器须有物理访问控制 |

### 三、数据传输安全

- 步态特征数据传输须采用加密通道
- 禁止通过不安全信道（如明文 HTTP）传输步态数据
- 传输前须验证接收方身份

### 四、数据使用安全

- 步态数据仅可用于采集时声明的目的
- 禁止将步态数据用于广告推送、人群行为分析等非授权用途
- 用于识别比对后，临时采集的步态数据应及时删除

### 五、数据共享与转让

- 向第三方提供步态数据须再次取得个人授权
- 须签订数据安全协议，明确接收方安全责任
- 国家安全、公共安全目的依法共享的，须有明确法律依据

### 六、数据销毁

- 步态特征模板销毁须使用安全删除技术（防止恢复）
- 存储介质报废前须进行数据清除或物理销毁
- 销毁过程须留存记录

## 个人权利保障

| 权利 | 要求 |
|------|------|
| 知情权 | 采集前明确告知，公共场所设置显著标识 |
| 拒绝权 | 在非强制场景下，个人有权拒绝步态采集 |
| 删除权 | 个人可申请删除其步态特征数据 |

## 与相关标准和法规的关联

| 标准/法规 | 关联说明 |
|----------|----------|
| 《个人信息保护法》第 28-32 条 | 步态信息属于生物识别信息，须满足敏感个人信息处理规则 |
| GB/T 35273-2020 | 个人信息安全规范，本标准是其在步态领域的专项细化 |

| GB/T 45574-2025 | 敏感个人信息处理安全要求，与本标准互补 |

## 部署注意事项

1. 部署公共场所步态识别系统前，应评估是否需要开展个人信息保护影响评估（PIA）
2. 须在显眼位置张贴告知标识，注明：采集目的、使用方式、数据保留期限、联系方式
3. 禁止将步态识别系统用于歧视性目的（如对特定群体的追踪监控）
