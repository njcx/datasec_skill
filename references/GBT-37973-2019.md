# GB/T 37973-2019 信息安全技术 大数据安全管理指南

## 基本信息

| 项目 | 内容 |
|------|------|
| 标准号 | GB/T 37973-2019 |
| 中文名称 | 信息安全技术 大数据安全管理指南 |
| 归口单位 | 全国网络安全标准化技术委员会（TC260） |
| 标准类型 | 推荐性国家标准（GB/T） |
| 发布年份 | 2019 年 |
| 实施日期 | 2020 年 3 月 1 日 |

## 标准简介

本标准针对大数据环境的特殊性，提供大数据安全管理的指导原则和管理措施，帮助组织建立面向大数据场景的安全管理体系。

## 主要内容框架

### 一、大数据安全管理总则

- 安全管理目标与原则
- 大数据安全角色与责任划分
  - **数据控制者**：决定数据处理目的和方式的主体
  - **数据处理者**：代表控制者处理数据的主体
  - **数据使用者**：利用数据产品/服务的主体

### 二、数据分类分级管理

- 依据数据敏感程度和业务重要性进行分类
- 针对不同级别数据制定差异化保护策略
- 数据标签与元数据管理

### 三、大数据平台安全

- 平台基础设施安全（计算、存储、网络）
- 大数据组件安全配置（Hadoop、Spark 等）
- 多租户隔离机制

### 四、数据处理安全

| 处理环节 | 主要安全要求 |
|----------|-------------|
| 数据采集 | 来源合法性验证、采集授权管理 |
| 数据存储 | 加密存储、访问控制、备份恢复 |
| 数据分析 | 分析操作审计、结果输出管控 |
| 数据共享 | 接口鉴权、传输加密、协议约束 |
| 数据销毁 | 安全清除、不可恢复性验证 |

### 五、安全运营与审计

- 日志管理与安全审计
- 异常行为检测与响应
- 安全事件处置流程

### 六、第三方大数据服务管理

- 供应商安全评估
- 合同安全条款要求
- 数据出境与跨组织流转

## 适用对象

- 大数据平台建设和运营单位
- 政务数据共享开放平台
- 金融、电信、医疗等数据密集型行业

## 与其他标准的关联

| 关联标准 | 关系说明 |
|----------|----------|
| GB/T 37988-2019（DSMM） | 本标准聚焦大数据场景，DSMM 提供能力成熟度评估框架 |
| GB/T 43697-2024（分类分级）| 本标准的分类管理内容需参照分类分级规则落地 |
| GB/T 39477-2020（政务数据）| 政务大数据共享场景的专项延伸 |

## 实践要点

1. 建立数据资产目录，明确每类数据的控制者和处理者
2. 结合数据生命周期，在各环节部署相应技术控制措施
3. 制定大数据安全操作规程并定期演练
