# 中华人民共和国《网络安全法》（CSL）

## 基本信息

| 项目 | 内容 |
|------|------|
| 全称 | 中华人民共和国网络安全法 |
| 英文简称 | CSL（Cybersecurity Law） |
| 通过日期 | 2016 年 11 月 7 日（十二届全国人大常委会第二十四次会议） |
| **施行日期** | **2017 年 6 月 1 日** |
| 结构 | 七章 七十九条 |
| 主管部门 | 国家网信部门负责统筹协调，公安、电信、保密等部门在各自职责范围内负责 |

---

## 一、适用范围与核心概念

### 适用范围（第2条）
在中华人民共和国境内建设、运营、维护和使用网络，以及网络安全的监督管理。

### 核心定义

| 概念 | 定义 |
|------|------|
| **网络** | 由计算机或其他信息终端及相关设备组成，按照一定规则和程序对信息进行收集、存储、传输、交换、处理的系统 |
| **网络安全** | 采取必要措施防范对网络的攻击、侵入、干扰、破坏和非法使用以及意外事故，使网络处于稳定可靠运行状态，保障网络数据完整性、保密性、可用性 |
| **网络运营者** | 网络的所有者、管理者和网络服务提供者 |
| **关键信息基础设施（CIIO）** | 公共通信、广播电视、能源、交通、水利、金融、公共服务、电子政务等**重要行业和领域**，以及其他一旦遭到破坏会严重危害国家安全的基础设施 |

---

## 二、网络安全等级保护制度（第21条）

**这是等保2.0（GB/T 22239-2019）的法律依据。**

国家实行网络安全等级保护制度，网络运营者须按要求履行安全保护义务：

- 制定内部安全管理制度和操作规程，确定网络安全负责人
- 采取防范计算机病毒和网络攻击、网络侵入等危害网络安全行为的技术措施
- 采取**监测、记录网络运行状态、网络安全事件**的技术措施，留存相关网络日志**不少于六个月**
- 采取数据分类、重要数据备份和加密等措施
- 法律、行政法规规定的其他义务

> ⚠️ **日志留存≥6个月**是法定要求，来源于本条，不仅是技术标准。

## 三、网络运营者的个人信息保护义务

### 基本义务（第40-44条）

| 条款 | 义务 |
|------|------|
| **第40条** | 对收集的用户信息**严格保密**，建立健全用户信息保护制度 |
| **第41条** | 收集、使用个人信息须**公开收集、使用规则**，明示目的、方式和范围，并经被收集者**同意**；不得收集与服务无关的信息；不得违法处理个人信息 |
| **第42条** | **不得泄露、篡改、毁损**收集的个人信息；未经同意不得向他人提供（经去标识化处理无法识别特定个人且不可复原的除外）；须采取技术措施防止信息泄露、损毁 |
| **第43条** | **个人有权要求网络运营者删除或更正**违规收集或不准确的个人信息，网络运营者须及时采取措施 |
| **第44条** | 任何个人和组织**不得窃取或非法获取、出售、提供**个人信息 |

## 四、网络产品和服务安全（第三章第一节）

- 网络产品、服务不得含有**恶意程序**（第22条）
- 网络产品、服务应当具备安全漏洞的**及时修复和通知**能力（第22条）
- 网络关键设备和网络安全专用产品须经**安全认证**或**安全检测**合格后方可销售（第23条）
- 网络运营者不得擅自终止安全维护（第22条）

---

## 五、关键信息基础设施（CIIO）特殊保护（第三章第二节）

### 重点保护义务

| 条款 | 义务 |
|------|------|
| **第34条** | CIIO 运营者须设置**专门安全管理机构和安全管理负责人**，定期对人员进行安全背景审查 |
| **第35条** | CIIO 采购网络产品和服务可能影响国家安全的，须经**国家安全审查** |
| **第36条** | CIIO 应当与**国内安全服务机构**签约（网络安全服务） |
| **第37条** | CIIO **在境内收集和产生的个人信息和重要数据须在境内存储**（数据本地化）；向境外提供须经**安全评估** |

> 第37条是中国**数据本地化**和**数据出境安全评估**制度的法律来源。

---

## 六、监测预警与应急处置（第四章）

- 国家建立网络安全**监测预警和信息通报**制度（第51条）
- 国家制定网络安全事件**应急预案**（第53条）
- 发生网络安全事件，网络运营者须立即启动应急预案，采取相应措施并**向有关主管部门报告**（第53条）
- 因网络安全事件危害社会秩序时，主管部门可采取**限制网络通信**等措施（第58条）

## 七、法律责任（第六章）——罚款速查

| 违规行为 | 条款 | 单位罚款 | 负责人罚款 |
|----------|------|---------|----------|
| 不履行等保义务（第21条） | 第59条 | 1万～10万元；情节严重：5万～50万元 | 5000元～5万；情节严重：1万～10万 |
| 不履行 CIIO 安全保护义务（第34-39条） | 第59条 | 10万～100万元 | 1万～10万 |
| 出售、提供个人信息（第42条）| 第64条 | 违法所得1～10倍；无违法所得处100万以下 | — |
| **侵害个人信息权利**（违反第41-43条）| 第64条第1款 | 警告 + 违法所得1～10倍；无违法所得处100万以下 | — |
| 网络产品、服务不符合要求 | 第60条 | 1万～10万；情节严重：5万～50万 | 5000～5万 |
| 数据本地化违规（第37条）| 第66条 | 5万～50万；情节严重：暂停业务、吊销执照 | 1万～10万 |

## 八、三法关系速查

| 维度 | 《网络安全法》CSL | 《数据安全法》DSL | 《个人信息保护法》PIPL |
|------|-----------------|-----------------|---------------------|
| 施行时间 | 2017年6月 | 2021年9月 | 2021年11月 |
| 保护对象 | 网络系统安全 | 所有数据 | 个人信息 |
| 核心制度 | 等保、CIIO 保护 | 数据分类分级、出境安全评估 | 个人信息处理规则、主体权利 |
| 处罚力度 | 最高100万元（侵害个人信息）| 最高1000万元（核心数据）| 最高5000万或年营业额5% |
| 数据本地化 | 第37条（CIIO 数据）| 第31条（重要数据出境）| 第38条（个人信息出境三路径）|
| 技术标准依托 | GB/T 22239（等保2.0）| GB/T 43697（分类分级）| GB/T 35273、GB/T 45574 |

> **三法并行适用**：同一数据处理行为可能同时触发三部法律，须综合评估，不得仅引用单一法律。
