# GB/T 45652-2025 网络安全技术 生成式人工智能预训练和优化训练数据安全规范

## 基本信息

| 项目 | 内容 |
|------|------|
| 标准号 | GB/T 45652-2025 |
| 中文名称 | 网络安全技术 生成式人工智能预训练和优化训练数据安全规范 |
| 归口单位 | 全国网络安全标准化技术委员会（TC260） |
| 标准类型 | 推荐性国家标准（GB/T） |
| 发布年份 | 2025 年 |

## 标准简介

本标准规定了用于训练生成式人工智能模型的数据（包括预训练数据和微调/优化训练数据）的安全要求，是《生成式人工智能服务管理暂行办法》的技术规范配套标准。

## 适用范围

- **预训练数据**：大规模语言模型、图像生成模型等基础模型训练所用的数据集
- **优化训练数据（微调数据）**：基于基础模型进行指令调优、RLHF 等优化训练的数据
- 适用于国内提供生成式 AI 服务的机构

## 训练数据安全要求框架

### 一、数据来源合法性

| 要求 | 说明 |
|------|------|
| 版权合规 | 训练数据须具备合法使用授权，不得大规模使用受版权保护的内容（未经授权） |
| 个人信息合规 | 含个人信息的训练数据须有合法处理依据（同意或其他合法基础） |
| 数据来源记录 | 须建立数据来源溯源记录，能证明来源合法性 |
| 爬虫合规 | 通过网络爬虫采集的数据，须遵守 robots.txt 规则及相关法规 |

### 二、训练数据内容安全

须对训练数据进行过滤和清洗，确保不含以下内容：

| 违禁内容类型 | 要求 |
|-------------|------|
| 违法有害内容 | 色情、暴力、恐怖主义、煽动颠覆国家政权等内容须清洗 |
| 歧视性内容 | 针对特定群体的歧视性、仇恨性内容 |
| 虚假信息 | 大量虚假事实性信息（影响模型输出质量和安全性） |
| 个人隐私数据 | 可识别特定个人的敏感信息（身份证号、手机号等） |

### 三、数据质量要求

- 训练数据须具备一定的**准确性**、**多样性**和**代表性**
- 须对数据进行去重处理，避免过拟合
- 数据标注须有质量控制流程（标注标准、一致性检查等）
- 须维护数据集版本记录

### 四、数据标注安全

（与 GB/T 45674-2025 联合实施）

- 标注人员须签署保密协议
- 含个人信息的标注数据须进行脱敏处理
- 标注任务平台须具备访问控制和数据泄露防护

### 五、数据存储与访问控制

- 训练数据集须加密存储（尤其是含敏感信息的数据）
- 限制训练数据的访问权限（最小权限原则）
- 训练过程须留存操作日志，确保可追溯

### 六、数据销毁

- 训练完成后不再需要的原始数据须及时安全删除
- 须评估训练后的模型是否存在数据"记忆"（memorization）风险

## 个人信息处理特殊要求

训练数据中若含个人信息，须满足：

- 处理须有合法依据（公共利益/科研须有相应认定）
- 须对个人信息进行最大程度的匿名化或去标识化处理
- 不得使用训练数据中的个人信息用于目标营销等超出原始目的的使用

## 与相关法规的关联

| 法律法规 | 关联说明 |
|----------|----------|
| 《生成式人工智能服务管理暂行办法》 | 本标准是该办法第七条"使用合法来源数据训练"的技术规范 |
| 《个人信息保护法》 | 训练数据中个人信息处理须满足 PIPL 要求 |
| 《著作权法》 | 训练数据的版权合规要求 |
| GB/T 45654-2025 | 生成式 AI 服务安全要求，本标准聚焦训练数据环节 |
| GB/T 45674-2025 | 数据标注安全规范，与本标准配套实施 |

## 对大模型研发团队的实践建议

1. **建立训练数据溯源体系**：记录每批训练数据的来源、授权情况、处理历史
2. **部署数据清洗流水线**：自动识别和过滤违禁内容、个人隐私信息
3. **开展数据集安全评估**：在训练前对数据集进行系统性安全检查
4. **建立数据记忆检测机制**：测试模型是否存在对训练数据的过度记忆（特别是个人信息）
5. **合规采购训练数据**：优先使用开放授权数据集，谨慎使用互联网爬取数据
