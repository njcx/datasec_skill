# GB/T 37932-2019 信息安全技术 数据交易服务安全要求

## 基本信息

| 项目 | 内容 |
|------|------|
| 标准号 | GB/T 37932-2019 |
| 中文名称 | 信息安全技术 数据交易服务安全要求 |
| 归口单位 | 全国网络安全标准化技术委员会（TC260） |
| 标准类型 | 推荐性国家标准（GB/T） |
| 发布年份 | 2019 年 |
| 实施日期 | 2020 年 3 月 1 日 |

## 标准简介

本标准规定了数据交易平台及数据交易各参与方的安全要求，旨在规范数据流通市场秩序，防止数据非法交易，是数据要素市场化流通的重要安全规范。

## 数据交易参与方

| 角色 | 说明 |
|------|------|
| 数据提供方 | 向交易平台提供数据产品/数据服务的主体 |
| 数据需求方 | 通过交易平台购买、使用数据产品/数据服务的主体 |
| 数据交易平台 | 为数据交易双方提供撮合、存证、结算等服务的中间机构 |

## 数据交易平台安全要求

### 平台资质与准入管理

- 对数据提供方进行资质审核（营业执照、授权证明等）
- 禁止含有违禁内容的数据上架（个人信息未授权、国家秘密等）
- 建立数据商品审核机制，上架前须审核合规性

### 平台技术安全

| 安全域 | 要求 |
|--------|------|
| 访问控制 | 用户身份认证、权限分级管理 |
| 数据存储 | 交易数据加密存储，防止泄露 |
| 传输安全 | 数据传输须加密，防中间人攻击 |
| 日志审计 | 记录交易全流程操作日志，可追溯 |
| 防攻击 | 具备 DDoS 防护、SQL 注入防护等基础防御能力 |

### 数据产品上架审核内容

- 数据来源合法性（授权链完整）
- 是否包含未授权个人信息
- 是否涉及国家秘密、重要数据
- 数据准确性和完整性说明

## 数据提供方安全要求

- 保证所提供数据的来源合法、权属清晰
- 对包含个人信息的数据须经脱敏或取得必要授权
- 数据描述（元数据）须准确，不得虚假标注
- 配合平台开展数据核验，接受必要的审计

## 数据需求方安全要求

- 明确声明数据使用目的，不得用于约定外用途
- 采购含个人信息的数据须具备合法处理依据
- 须对采购数据采取相应的安全保护措施
- 发现数据存在违规问题应及时告知平台

## 数据交易禁止事项

以下数据**不得**通过交易平台流通：

- 未经授权的个人信息数据集
- 国家秘密、军事数据
- 国家明令禁止开放的政务数据
- 非法爬取的数据
- 经法院、仲裁机构裁定禁止交易的数据

## 争议处理与追责

- 交易平台须建立争议处理机制（鉴定、仲裁、调解）
- 平台须保留交易存证，留存期限不少于 5 年
- 数据事故发生时，各方责任依合同约定和本标准划分

## 与相关法规的关联

| 法律法规 | 关联说明 |
|----------|----------|
| 《数据安全法》第四章 | 数据交易中介服务机构的义务与本标准高度对应 |
| 《个人信息保护法》 | 涉及个人信息的数据交易须同时满足 PIPL 要求 |
| 《"数据二十条"》 | 支撑数据要素市场化流通的安全规范基础 |
| GB/T 43697-2024 | 交易前须对数据完成分类分级，确定可流通性 |

## 对数据交易所的参考价值

本标准可为上海数据交易所、北京国际大数据交易所等数据交易机构提供：
- 平台安全建设的技术基准
- 数据商品合规审核的评判依据
- 参与方安全协议的参考框架
