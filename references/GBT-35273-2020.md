# GB/T 35273-2020 信息安全技术 个人信息安全规范

## 基本信息

| 项目 | 内容 |
|------|------|
| 标准号 | GB/T 35273-2020 |
| 中文名称 | 信息安全技术 个人信息安全规范 |
| 归口单位 | 全国网络安全标准化技术委员会（TC260） |
| 标准类型 | 推荐性国家标准（GB/T） |
| 替代标准 | GB/T 35273-2017 |
| 发布日期 | 2020 年 3 月 6 日 |
| 实施日期 | 2020 年 10 月 1 日 |

## 标准简介

本标准规定了开展个人信息处理活动应遵循的安全规范，是《个人信息保护法》实施前国内个人信息保护领域影响最广泛的技术标准，也是 App 专项治理、网信执法检查的重要参考依据。

## 核心概念

| 概念 | 定义说明 |
|------|----------|
| 个人信息 | 以电子或其他方式记录的，能够单独或与其他信息结合识别特定自然人的各种信息 |
| 个人敏感信息 | 一旦泄露或滥用，可能导致个人遭受歧视或人身、财产损害的个人信息 |
| 个人信息控制者 | 有权决定个人信息处理目的、方式的组织或个人 |
| 授权同意 | 个人信息主体对其个人信息进行特定处理活动明确作出的同意 |

### 个人敏感信息类型（示例）

- 财产信息（银行账号、征信信息、流水记录）
- 健康生理信息（个人基因、医疗记录、残疾信息）
- 个人生物识别信息（指纹、声纹、虹膜、人脸）
- 个人身份信息（身份证、护照、驾照）
- 网络身份标识信息（账号密码、密保信息）
- 14 岁以下未成年人信息

## 个人信息处理原则

1. **权责一致**：谁控制谁负责
2. **目的明确**：处理目的具体、清晰、合法
3. **选择同意**：给予个人充分的知情权和自主选择权
4. **最少够用**：收集数量和范围不超过实现目的最低限度
5. **公开透明**：处理规则公开，接受监督
6. **确保安全**：建立与风险相适应的安全防护措施
7. **主体参与**：保障个人信息主体查询、更正、删除等权利

## 个人信息处理各环节要求

### 收集

- 须明确告知并取得授权同意
- 禁止强制捆绑授权（与服务无关的权限）
- 收集个人敏感信息须单独授权同意
- 须提供隐私政策，内容须符合规范要求

### 存储

- 个人信息存储在境内（跨境须合规评估）
- 敏感信息加密存储
- 超过保存期限或实现目的后应删除或匿名化

### 使用

- 不得超出约定目的使用
- 使用个人敏感信息须再次确认
- 禁止对个人信息主体进行歧视性差异化处理

### 共享与转让

- 原则上须重新取得个人信息主体授权
- 签订数据处理协议，明确接收方义务
- 提供业务功能时发生资产转让，须提前告知

### 公开披露

- 须取得个人信息主体的明确同意
- 披露个人敏感信息须逐项授权

### 委托处理

- 与受托方签订协议，规定处理目的、方式、安全措施
- 对受托方开展监督检查

## 个人信息主体的权利

| 权利 | 要求 |
|------|------|
| 知情权 | 及时、明确地告知处理规则 |
| 决定权/同意权 | 给予用户充分选择，可撤回同意 |
| 查询权 | 提供查询渠道，15 个工作日内响应 |
| 更正权 | 提供更正或投诉渠道 |
| 删除权 | 满足特定条件下须删除 |
| 注销权 | 提供注销账户功能 |

## 安全管理要求

- 建立个人信息安全影响评估（PIA）机制
- 大规模处理个人信息须设立个人信息保护专职岗位或机构
- 制定个人信息安全事件应急响应预案
- 发生个人信息安全事件须及时通知主体，严重情形须向主管部门报告
