# GB/T 45574-2025 数据安全技术 敏感个人信息处理安全要求

## 基本信息

| 项目 | 内容 |
|------|------|
| 标准号 | GB/T 45574-2025 |
| 中文名称 | 数据安全技术 敏感个人信息处理安全要求 |
| 归口单位 | 全国网络安全标准化技术委员会（TC260） |
| 标准类型 | 推荐性国家标准（GB/T） |
| 发布年份 | 2025 年 |

## 标准简介

本标准专门针对敏感个人信息的处理活动，规定了比一般个人信息更为严格的安全要求，是《个人信息保护法》第二章（敏感个人信息处理规则）的核心技术支撑标准。

## 敏感个人信息的界定

《个人信息保护法》第 28 条规定，敏感个人信息是指一旦泄露或者非法使用，容易导致自然人的人格尊严受到侵害或者人身、财产安全受到危害的个人信息。

### 敏感个人信息类型

| 类型 | 示例 |
|------|------|
| 生物识别信息 | 指纹、面部识别、虹膜、声纹、步态、基因 |
| 宗教信仰 | 宗教、信仰、入教记录 |
| 特定身份 | 残疾信息、政治身份 |
| 医疗健康 | 诊疗记录、处方、体检报告、病史 |
| 金融账户 | 银行卡号、支付密码、信用报告 |
| 行踪轨迹 | 精确位置、出行记录、住宿记录 |
| 不满 14 周岁未成年人的个人信息（全类型均属敏感） |

## 处理敏感个人信息的特殊要求

### 告知与同意

- **单独同意**：须单独取得个人同意（不能与其他条款合并授权）
- **书面同意**：法律法规规定须书面同意的，须采用书面形式
- **明确目的**：明确告知处理的必要性及对个人权益的影响
- **不可默认**：不得通过默认勾选等方式获取同意

### 技术安全措施

| 措施类别 | 具体要求 |
|----------|----------|
| 加密保护 | 存储和传输均须加密，加密强度不低于 AES-128 |
| 访问控制 | 最小权限原则，敏感信息按需分配访问权限 |
| 去标识化 | 内部使用时优先采用去标识化处理 |
| 安全审计 | 记录访问、修改、删除等操作日志，留存不少于 6 个月 |
| 存储隔离 | 敏感信息与一般信息分库或分区存储 |

### 处理限制

- 不得仅以自动化决策方式处理影响个人重大权益的敏感信息
- 原则上不得将敏感信息用于个性化推荐
- 处理超过 100 万人的生物识别信息须开展安全影响评估（PIA）

### 未成年人保护

- 处理不满 14 周岁未成年人信息须取得监护人同意
- 须制定专项未成年人个人信息处理规则
- 提供专门面向未成年人的产品/服务，须制定隐私政策

## 安全影响评估（PIA）

在以下情形处理敏感个人信息前，须开展个人信息保护影响评估：

- 处理生物识别信息
- 大规模处理行踪轨迹
- 向境外提供敏感个人信息
- 处理敏感信息用于自动化决策

**评估内容应包括：**
- 处理活动的合法性、正当性分析
- 识别可能对个人权益造成的风险
- 拟采取的保护措施及其有效性
- 评估报告留存不少于 3 年
