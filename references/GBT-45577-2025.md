# GB/T 45577-2025 数据安全技术 数据安全风险评估方法

## 基本信息

| 项目 | 内容 |
|------|------|
| 标准号 | GB/T 45577-2025 |
| 中文名称 | 数据安全技术 数据安全风险评估方法 |
| 归口单位 | 全国网络安全标准化技术委员会（TC260） |
| 标准类型 | 推荐性国家标准（GB/T） |
| 发布年份 | 2025 年 |

## 标准简介

本标准规定了数据安全风险评估的方法、流程、评估内容和报告要求，是《数据安全法》第三十条"重要数据处理者应当定期对其数据活动开展风险评估"的技术规范落地。

## 适用范围

- **重要数据处理者**（法定义务）
- 核心数据处理者
- 其他希望开展数据安全风险评估的组织（参考使用）

## 风险评估基本概念

| 概念 | 说明 |
|------|------|
| 数据安全风险 | 数据在处理过程中遭受破坏、泄露、篡改、非法使用等的可能性及其影响 |
| 威胁 | 可能导致数据安全事件的潜在原因 |
| 脆弱性 | 数据处理系统或管理机制中可被威胁利用的弱点 |
| 风险值 | 威胁发生概率 × 影响程度的综合评估结果 |

## 风险评估流程

```
1. 评估准备
   ├── 明确评估范围（数据类型、处理系统、业务场景）
   ├── 组建评估团队（内部+可引入第三方）
   └── 收集相关文档和背景信息

2. 数据资产识别
   ├── 梳理数据资产目录
   ├── 确认数据分类分级
   └── 识别数据流转路径

3. 威胁识别
   ├── 外部威胁（黑客攻击、数据窃取）
   ├── 内部威胁（员工滥用、误操作）
   └── 环境威胁（自然灾害、设备故障）

4. 脆弱性识别
   ├── 技术脆弱性（系统漏洞、配置缺陷）
   ├── 管理脆弱性（制度缺失、流程不规范）
   └── 人员脆弱性（安全意识不足）

5. 风险分析与评价
   ├── 计算风险值（可能性 × 影响度）
   ├── 风险等级划分（高/中/低）
   └── 确定需优先处理的风险

6. 风险处置建议
   ├── 风险消除（修复漏洞、删除不必要数据）
   ├── 风险降低（加强控制措施）
   ├── 风险转移（购买保险、外包）
   └── 风险接受（低风险、成本过高）

7. 编写评估报告

8. 持续监控与复评
```

## 风险评估重点内容

### 数据处理活动评估

| 处理环节 | 评估重点 |
|----------|----------|
| 数据采集 | 采集合法性、最小化程度 |
| 数据存储 | 加密措施、访问控制有效性 |
| 数据使用 | 权限管控、使用范围合规性 |
| 数据共享 | 接收方安全能力、协议完整性 |
| 数据跨境 | 境外接收方合规性、安全评估情况 |
| 数据销毁 | 销毁程序规范性、彻底性 |

### 重点评估场景

- 大规模个人信息处理活动
- 向境外提供数据
- 数据产品上线前的安全评估
- 并购重组涉及数据资产转移

## 风险等级划分参考

| 风险等级 | 描述 | 处置要求 |
|----------|------|----------|
| 高风险 | 严重影响数据安全，须立即整改 | 立即制定整改计划，限期完成 |
| 中风险 | 存在一定安全隐患，影响可控 | 纳入年度整改计划 |
| 低风险 | 影响轻微，当前控制措施基本有效 | 持续监控，酌情改进 |

## 评估报告主要内容

1. 评估概述（目的、范围、方法、团队）
2. 数据资产清单及分级结果
3. 威胁和脆弱性识别列表
4. 风险评估结果（风险矩阵）
5. 风险处置建议及优先级
6. 评估结论
7. 后续工作建议

> 重要数据处理者须**每年**至少开展一次风险评估，并将评估报告留存备查，必要时向主管部门报告。
