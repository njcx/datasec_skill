# GB/T 39477-2020 信息安全技术 政务信息共享 数据安全技术要求

## 基本信息

| 项目 | 内容 |
|------|------|
| 标准号 | GB/T 39477-2020 |
| 中文名称 | 信息安全技术 政务信息共享 数据安全技术要求 |
| 归口单位 | 全国网络安全标准化技术委员会（TC260） |
| 标准类型 | 推荐性国家标准（GB/T） |
| 发布年份 | 2020 年 |

## 标准简介

本标准规定了政务部门开展信息共享时应满足的数据安全技术要求，包括共享平台安全、共享数据安全管理和相关技术措施，是政务数字化建设中保障数据安全的重要技术依据。

## 政务信息共享的安全挑战

- 跨部门、跨层级共享涉及多个安全域的边界管控
- 政务数据含有大量个人信息和敏感业务数据
- 共享过程中的数据被滥用风险
- 数据权属不清晰导致责任归属困难

## 安全要求框架

### 一、共享数据安全管理

#### 数据分类分级

- 政务信息须先完成分类分级，按级别确定共享范围
- **无条件共享**：可直接对所有部门开放
- **有条件共享**：经审批后向特定部门开放
- **不予共享**：仅供本部门内部使用

#### 共享审批管理

- 建立共享申请、审批、授权的完整流程
- 审批须明确：共享目的、使用期限、使用范围、安全责任
- 共享协议中须包含数据安全责任条款

#### 数据质量管理

- 提供方须保证数据的准确性、完整性、时效性
- 元数据须完整描述数据来源、更新频率等

### 二、共享平台安全技术要求

| 安全域 | 技术要求 |
|--------|----------|
| 身份认证 | 各接入部门须进行身份鉴别，支持强认证（数字证书等） |
| 访问控制 | 基于角色的访问控制，最小权限原则 |
| 数据传输 | 采用 TLS/SSL 等协议加密传输，防篡改 |
| 数据存储 | 敏感政务数据加密存储，分区隔离 |
| 安全审计 | 记录全量数据访问、共享、操作日志，留存不少于 6 个月 |
| 接口安全 | API 接口鉴权，防止未授权调用 |

### 三、数据使用安全

- 需求方不得将共享数据用于约定目的以外的用途
- 含个人信息的数据须在使用前脱敏处理
- 禁止将共享数据二次对外提供（未经原共享方授权）
- 超出使用期限后须按规定删除或归还数据

### 四、应急与追溯

- 建立数据安全事件应急响应预案
- 平台须具备数据访问行为的追溯能力
- 发生数据安全事件须及时报告并溯源

## 个人信息保护特殊要求

政务共享涉及个人信息时，还须满足：

- 明确法定共享依据（无需单独取得个人授权，但须有法规依据）
- 接收部门须在业务范围内使用
- 不得向社会公开含个人信息的原始数据集

## 政务数据共享范围的判断流程

```
确认数据级别
     ↓
判断是否属于无条件共享类
     ↓ 否
判断申请方是否满足共享条件
     ↓ 满足
审批 → 签订共享协议 → 授权访问 → 监督使用 → 到期清除
```
