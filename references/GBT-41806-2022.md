# GB/T 41806-2022 信息安全技术 基因识别数据安全要求

## 基本信息

| 项目 | 内容 |
|------|------|
| 标准号 | GB/T 41806-2022 |
| 中文名称 | 信息安全技术 基因识别数据安全要求 |
| 归口单位 | 全国网络安全标准化技术委员会（TC260） |
| 标准类型 | 推荐性国家标准（GB/T） |
| 发布日期 | 2022 年 10 月 12 日 |
| 实施日期 | 2023 年 5 月 1 日 |

## 标准简介

本标准是生物识别数据安全系列标准之一，专门针对基因识别数据的安全要求进行规定。基因数据因其极高的隐私敏感性和不可变更性，受到法律法规的特别保护。

## 基因数据的特殊性

基因信息是个人信息中**敏感程度最高**的类别之一：

- **终身唯一性**：基因序列不会随时间变化，泄露影响终身
- **家族关联性**：个人基因信息同时涉及其血缘亲属的隐私
- **医疗预测性**：可预测个人健康风险，被歧视或拒保的风险极高
- **国家战略性**：大规模人类基因数据属于重要数据，跨境受严格管控

## 适用场景

- 基因检测公司（消费级和医疗级）
- 医院及医学研究机构
- 法医鉴定机构
- 生物信息学研究平台

## 主要安全要求

### 一、数据采集安全

- 须获得被采集人的**明确知情同意**（书面或电子方式，须保留记录）
- 告知内容须包括：采集目的、数据用途、保存期限、共享范围
- 禁止在个人不知情的情况下采集基因数据
- 儿童基因数据须取得监护人同意

### 二、数据存储安全

| 要求 | 说明 |
|------|------|
| 加密存储 | 基因数据须加密存储，推荐使用国密算法 |
| 隔离存储 | 基因数据与个人身份标识信息分开存储 |
| 访问控制 | 最小权限，敏感操作须双人授权或审批 |
| 境内存储 | 中国公民基因数据须存储在境内服务器 |
| 备份安全 | 备份数据同等安全要求，须加密备份 |

### 三、数据使用安全

- 基因数据须严格用于采集时声明的目的（诊疗、科研等）
- **禁止**将基因数据用于：
  - 招聘就业歧视
  - 保险费率歧视
  - 商业广告画像
  - 刑事案件以外的法律目的（须有明确授权）
- 内部使用须记录详细的访问和使用日志

### 四、数据共享与对外提供

- 向第三方科研机构共享，须签订数据使用协议，明确用途限制
- 共享匿名化处理的基因数据时，须评估重标识化风险
- **向境外提供须满足**：
  - 通过国家卫生健康委员会的安全审查
  - 同时满足《人类遗传资源管理条例》的要求
  - 不得将中国人类遗传资源原材料（含数据）违规出境

### 五、数据销毁

- 超出保留期限的基因数据须安全删除（不可恢复）
- 存储介质报废须进行专业数据清除或物理销毁
- 留存销毁记录

## 基因数据的特殊法规背景

除数据安全标准外，基因数据还受以下专项法规约束：

| 法律法规 | 要点 |
|----------|------|
| 《人类遗传资源管理条例》（2019）| 禁止未经批准将人类遗传资源信息向境外提供 |
| 《生物安全法》（2021）| 人类遗传资源属于生物安全管理范畴 |
| 《个人信息保护法》第 28 条 | 基因信息属于敏感个人信息，适用特殊保护规则 |
| 《数据安全法》 | 大规模基因数据可能属于"重要数据"，须开展风险评估 |

## 安全影响评估要求

处理以下情形的基因数据前，须开展**个人信息保护影响评估（PIA）**：

- 大规模基因数据处理（超过 100 万人）
- 向境外提供基因数据
- 用于自动化决策（如基因风险预测产品）
