# GB/T 37988-2019 信息安全技术 数据安全能力成熟度模型（DSMM）

## 基本信息

| 项目 | 内容 |
|------|------|
| 标准号 | GB/T 37988-2019 |
| 英文简称 | DSMM（Data Security Capability Maturity Model） |
| 中文名称 | 信息安全技术 数据安全能力成熟度模型 |
| 归口单位 | 全国网络安全标准化技术委员会（TC260） |
| 标准类型 | 推荐性国家标准（GB/T） |
| 发布日期 | 2019 年 8 月 30 日 |
| 实施日期 | 2020 年 3 月 1 日 |
| 主要起草单位 | 阿里巴巴、中国电子技术标准化研究院、华为、中国移动等 30+ 家单位 |

## 标准简介

DSMM 以组织的数据为中心，围绕数据全生命周期，从四个能力维度、五个成熟度等级，评判组织的数据安全能力，是我国首个面向数据安全治理实践的国家级标准体系。

## 三维模型架构

### 维度一：安全能力（4 个关键能力）

| 能力维度 | 说明 |
|----------|------|
| 组织建设 | 数据安全组织架构、岗位职责设置 |
| 制度流程 | 数据安全管理制度、操作规程 |
| 技术工具 | 数据安全防护技术和工具的使用 |
| 人员能力 | 数据安全意识与专业能力培养 |

### 维度二：能力成熟度等级（5 级）

| 等级 | 名称 | 主要特征 |
|------|------|----------|
| 1 级 | 非正式执行级 | 随机无序，依赖个人经验，无法复制 |
| 2 级 | 计划跟踪级 | 有基本制度，部分场景执行，缺乏系统性 |
| 3 级 | 充分定义级 | 制度完善，全面落地，可稳定执行 |
| 4 级 | 量化控制级 | 量化管理，基于数据驱动安全决策 |
| 5 级 | 持续优化级 | 持续改进，业界领先水平 |

> 大部分组织适合申请 2 级认证；3 级适合数据安全实践水平较高的组织；5 级暂不开放申请。

### 维度三：数据安全过程（6+1 个过程维度，30 个过程域）

**数据生存周期安全过程（6 个阶段）：**

| 阶段 | 典型安全要求 |
|------|-------------|
| 数据采集安全 | 采集合法性、数据源验证、最小化采集 |
| 数据传输安全 | 传输加密、完整性校验、安全通道 |
| 数据存储安全 | 加密存储、访问控制、备份容灾 |
| 数据处理安全 | 脱敏处理、操作审计、权限最小化 |
| 数据交换安全 | 接口鉴权、数据水印、输出管控 |
| 数据销毁安全 | 安全删除、介质销毁、不可恢复验证 |

**通用安全过程（1 个）：** 覆盖所有阶段的通用安全能力（如合规管理、安全审计等）。

## 评估流程

1. 数据安全差距分析（对照标准自评估）
2. 建立数据管理组织，完善制度体系
3. 内部运行并开展自评估
4. 向认证机构提出申请
5. **第一阶段**：文件审查（自评估表及佐证材料）
6. **第二阶段**：现场评价（覆盖业务系统所涉物理场所）
7. 颁发对应等级证书

## 评分方法

- 对每个过程域（PA）的四个能力维度（BP）逐一打分
- 计算平均分并修正，得出 PA 分值
- 综合各 PA 得分形成整体能力等级结论

## 与相关法规的关联

| 法律法规 | 关联说明 |

| 《数据安全法》 | DSMM 是落实数据安全管理义务的重要参考依据 |
| 《个人信息保护法》 | 个人信息处理环节的安全能力可通过 DSMM 量化评估 |
| 《网络安全法》 | 网络运营者数据保护义务的能力评估框架 |

## 适用价值

1. 帮助组织量化自身数据安全能力短板
2. 为监管部门提供数据安全监管的评估依据
3. 促进上下游数据交换方之间的安全互信
4. 提升市场竞争力，增强客户和合作伙伴信任
