# GB/T 45674-2025 网络安全技术 生成式人工智能数据标注安全规范

## 基本信息

| 项目 | 内容 |
|------|------|
| 标准号 | GB/T 45674-2025 |
| 中文名称 | 网络安全技术 生成式人工智能数据标注安全规范 |
| 归口单位 | 全国网络安全标准化技术委员会（TC260） |
| 标准类型 | 推荐性国家标准（GB/T） |
| 发布年份 | 2025 年 |

## 标准简介

本标准规定了生成式人工智能训练数据标注活动的安全要求，涵盖标注任务委托方、标注平台运营方和标注人员三方的安全责任和技术要求，是 AI 训练数据安全管理体系的重要组成部分。

## 适用角色与场景

| 角色 | 说明 |
|------|------|
| 标注任务委托方 | 大模型研发机构，将标注任务外包给标注公司 |
| 标注平台运营方 | 专业数据标注公司，提供标注平台和人员 |
| 标注人员 | 执行具体标注工作的众包或全职人员 |

## 主要安全要求

### 一、标注数据安全管理

#### 数据分类分级

- 委托方须在发布标注任务前对标注数据进行分类分级
- 含个人信息的数据须在标注前完成**脱敏处理**
- 含商业秘密的数据须标注保密级别，相应提高访问控制要求

#### 数据传输安全

- 委托方向标注平台传输数据须使用加密通道（TLS/VPN）
- 禁止通过即时通信工具（微信、钉钉）明文传输标注数据
- 大批量数据传输须使用安全的文件传输协议

#### 数据存储安全

- 标注平台须对存储的标注数据加密
- 标注数据不得存储在标注人员个人设备上
- 须设置数据访问权限，标注人员仅能访问其任务范围内的数据

### 二、标注平台技术安全要求

| 安全域 | 要求 |
|--------|------|
| 身份认证 | 标注人员须实名注册并通过身份验证 |
| 访问控制 | 按任务分配数据访问权限，互不交叉 |
| 截图/下载防护 | 平台须具备防止数据截图、下载、外发的技术措施 |
| 操作日志 | 记录标注人员的全部操作行为，支持审计追溯 |
| 水印 | 对展示给标注人员的数据加注不可见水印，便于泄露溯源 |
| 环境隔离 | 标注任务在隔离环境中执行，防止数据跨任务泄露 |

### 三、标注人员安全管理

- 标注人员须签署**保密协议**，明确数据保密义务
- 禁止标注人员将标注数据截图、复制、外传
- 标注人员应接受数据安全意识培训
- 涉及高度敏感数据的标注任务，须通过背景调查

### 四、标注内容安全

标注任务本身可能涉及有害内容（用于训练内容安全分类器），须：

- 建立**有害内容暴露管理机制**，保护标注人员心理健康
- 限制标注人员单次接触有害内容的时长和数量
- 提供心理援助渠道
- 有害内容标注任务须由经过专项培训的人员执行

### 五、标注质量与安全审核

- 建立标注数据质量检查机制，识别恶意标注（故意注入有害数据）
- 对最终交付的标注数据集进行安全复检
- 标注结果须有审核人员复核，不得直接用于模型训练而不经检验

### 六、合同与协议要求

委托方与标注平台签订合同须包含：

- 数据安全责任划分条款
- 数据保密条款和违约责任
- 数据使用范围限制（不得用于第三方）
- 项目结束后的数据归还/销毁要求
- 数据安全事件通报义务

## 数据标注安全事件处置

- 发现标注数据泄露须在 **24 小时内**通知委托方
- 委托方须评估泄露影响，决定是否启动应急响应
- 泄露溯源须利用水印等技术手段定位责任方

## 对数据标注外包的风险提示

外包数据标注是目前大模型研发中最常见的数据安全风险点：

1. **外包链条过长**：委托方 → 标注公司 → 分包商 → 众包人员，每个环节都有泄露风险
2. **众包人员管控难**：难以对大量兼职标注人员实施有效安全管控
3. **有害内容外溢**：内容安全标注数据若泄露，可能直接造成社会危害
4. **竞争对手渗透**：竞争对手可能通过渗透标注团队获取训练数据

> 建议：对含商业秘密或高价值数据的标注任务，优先考虑内部标注团队，减少外包环节。
