# GB 46864-2025 数据安全技术 电子产品信息清除技术要求

## 基本信息

| 项目 | 内容 |
|------|------|
| 标准号 | GB 46864-2025 |
| 中文名称 | 数据安全技术 电子产品信息清除技术要求 |
| 归口单位 | 全国网络安全标准化技术委员会（TC260） |
| **标准类型** | **强制性国家标准（GB）** ⚠️ |
| 发布年份 | 2025 年 |
| **强制实施日期** | **2027 年 1 月 1 日** |

> ⚠️ **注意**：本标准为强制性国家标准，不同于推荐性（GB/T）标准，从实施日期起所有相关电子产品的生产和销售**必须**满足本标准要求。

## 标准简介

本标准规定了电子产品在出厂、售后、报废等场景下对存储设备进行信息清除的技术要求，旨在防止个人信息和敏感数据因设备流转而泄露。

## 适用产品范围

- 智能手机、平板电脑
- 个人电脑（台式机、笔记本电脑）
- 硬盘（HDD、SSD、eMMC 等）
- 服务器、存储设备
- 具有存储功能的消费类电子产品（智能音箱、摄像头等）
- 工业控制设备中含存储模块的设备

## 信息清除的触发场景

| 场景 | 说明 |
|------|------|
| 设备出售/转让 | 二手交易、以旧换新 |
| 设备送修 | 送厂维修前须清除用户数据 |
| 设备报废 | 淘汰处置、电子垃圾回收 |
| 产品出厂前恢复出厂 | 确保出厂设备不含前用户数据 |
| 用户主动"恢复出厂设置" | 须满足不可恢复性要求 |

## 信息清除技术要求

### 基本原则

- 信息清除后，数据须**不可恢复**（包括通过专业数字取证工具）
- 清除方式须与存储介质类型相适应
- 须提供用户可操作的信息清除功能

### 不同存储介质的清除方法

#### 机械硬盘（HDD）

| 清除方法 | 技术要求 |
|----------|----------|
| 覆写清除 | 须使用经认可的覆写算法（至少 1 次全盘覆写，推荐 3 次以上） |
| 消磁清除 | 使用满足强度要求的消磁设备 |
| 物理销毁 | 粉碎或熔融，适用于无法软件清除的场景 |

#### 固态硬盘（SSD / eMMC / NVMe）

- SSD 的特殊性：覆写不能保证数据完全清除（闪存的均衡写入机制）
- 须支持 **ATA Secure Erase** 或 **NVMe Format with Secure Erase** 命令
- 厂商须公示其支持的安全清除命令和效果

#### 移动设备（智能手机/平板）

- 须支持安全出厂重置功能（加密后再清除，确保加密密钥一并清除）
- 系统的"恢复出厂设置"功能必须满足信息清除的不可恢复性要求

### 清除结果验证

- 产品须具备或支持信息清除结果的验证机制
- 企业级产品须能生成清除操作日志和证明报告

## 对消费者的影响

| 场景 | 消费者须注意 |
|------|-------------|
| 出售旧手机/电脑 | 须使用"安全出厂重置"而非普通"恢复出厂设置" |
| 送修设备 | 建议提前备份并清除数据后再送修 |
| 电子垃圾回收 | 须确认回收机构具备安全数据清除能力 |

## 对企业的影响

| 主体 | 合规要求 |
|------|----------|
| 电子产品制造商 | 2027 年 1 月 1 日前，产品须符合本标准要求 |
| IT 资产管理企业 | 批量处置设备时须按标准清除数据并留存记录 |
| 维修服务商 | 接收送修设备前须告知用户清除数据 |
| 数据中心/服务器运营商 | 硬件退役时须按标准要求清除数据 |

## 与相关法规的关联

| 法律法规 | 关联说明 |
|----------|----------|
| 《个人信息保护法》第 47 条 | 处理目的实现后须删除个人信息，本标准规定技术实现方式 |
| 《数据安全法》 | 数据安全处置的强制性技术规范 |
| GB/T 35273-2020 | 个人信息的数据销毁要求，本标准提供具体技术规范 |

## 合规准备建议（面向制造商）

1. 评估现有产品是否支持符合标准的安全清除功能
2. 规划固件/软件升级方案，确保 2027 年前完成整改
3. 更新产品说明书，向用户说明安全清除的正确操作方式
4. 对企业级产品，增加清除报告生成功能
