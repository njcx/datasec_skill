# GB/T 45654-2025 网络安全技术 生成式人工智能服务安全基本要求

## 基本信息

| 项目 | 内容 |
|------|------|
| 标准号 | GB/T 45654-2025 |
| 中文名称 | 网络安全技术 生成式人工智能服务安全基本要求 |
| 归口单位 | 全国网络安全标准化技术委员会（TC260） |
| 标准类型 | 推荐性国家标准（GB/T） |
| 发布年份 | 2025 年 |

## 标准简介

本标准规定了生成式人工智能服务在数据安全、内容安全、模型安全、服务安全等方面的基本要求，是《生成式人工智能服务管理暂行办法》的核心技术配套标准。

## 适用范围

- 大语言模型（LLM）服务提供者
- 文生图、文生视频等生成式内容服务
- 基于大模型的对话/问答产品
- 将开源或商业基础模型进行二次开发并对外提供服务的机构

## 安全要求框架

### 一、训练数据安全

（详见 GB/T 45652-2025，本标准纲领性要求）

- 训练数据来源合法合规
- 数据内容须经过安全过滤
- 个人信息处理须符合法律规定

### 二、模型安全

| 安全类别 | 要求 |
|----------|------|
| 模型评估 | 服务上线前须开展安全评估，识别模型的安全缺陷 |
| 对抗鲁棒性 | 须具备抵御提示词注入攻击（Prompt Injection）的基础防护 |
| 幻觉控制 | 须采取措施降低模型输出虚假信息的概率 |
| 能力边界说明 | 向用户明确告知模型能力范围和局限性 |

### 三、内容安全

生成内容须满足的安全要求：

| 违禁内容类型 | 要求 |
|-------------|------|
| 违法内容 | 拒绝生成违法有害内容（色情、暴力、恐怖主义等） |
| 颠覆政权内容 | 不生成煽动颠覆国家政权、分裂国家的内容 |
| 虚假信息 | 减少传播可能造成混乱的虚假事实性内容 |
| 歧视性内容 | 不生成针对特定群体的歧视性内容 |
| 侵权内容 | 减少大段复制版权内容，避免侵犯著作权 |

**内容安全实现方式：**
- 输入过滤（识别并拒绝有害问题）
- 输出过滤（检测并屏蔽有害生成内容）
- RLHF（基于人类反馈的强化学习）调优
- 内容安全分类器

### 四、用户交互安全

- **AI 身份透明**：须告知用户其在与 AI 交互，不得欺骗用户误认为在与真人交流
- **虚假人设**：不得为 AI 设计用于欺骗的人类身份
- **明显标注**：AI 生成的内容（尤其是图片、视频）须有显著标识
- **拒绝服务说明**：拒绝用户请求时须给出说明，不得无故静默拒绝

### 五、数据安全与隐私保护

- 用户对话数据须有明确的保留期限
- 默认情况下，用户对话数据不得用于模型训练（须单独授权）
- 系统须具备用户数据访问、更正、删除的通道
- 对话数据加密存储

### 六、服务安全

| 安全要求 | 说明 |
|----------|------|
| 可用性 | 须具备基础的高可用保障措施 |
| 接口安全 | API 须有认证鉴权机制，防止未授权调用 |
| 滥用防护 | 须具备对服务滥用（如大规模垃圾内容生成）的检测和限制机制 |
| 日志审计 | 须记录服务使用日志，支持必要的溯源 |

## 安全评估要求

在服务上线前，须开展安全评估，重点检验：

1. 内容安全（违禁内容生成测试）
2. 提示词攻击防护能力
3. 个人信息泄露风险
4. 数据安全合规性

> 依据《生成式人工智能服务管理暂行办法》，提供具有舆论属性或社会动员能力的生成式 AI 服务，须在上线前进行**安全评估备案**。

## 与相关法规的关联

| 法律法规 | 关联说明 |
|----------|----------|
| 《生成式人工智能服务管理暂行办法》 | 本标准是该办法的核心技术规范 |
| 《网络安全法》 | 网络安全等级保护要求适用于 AI 服务平台 |
| 《个人信息保护法》 | 用户数据处理须满足 PIPL 要求 |
| GB/T 45652-2025 | 本标准的训练数据安全要求的详细规范 |
| GB/T 45674-2025 | 数据标注安全，与训练数据安全配套 |

## 对 AI 产品团队的实践建议

1. 建立**内容安全测试红队**，在产品上线前进行系统性对抗测试
2. 部署**输入+输出双层**内容安全过滤器
3. 在隐私政策中明确说明对话数据的使用方式和保留期限
4. 设计"AI 身份透明"机制，在适当位置提示用户与 AI 交互
5. 建立用户反馈机制，持续改进内容安全能力
